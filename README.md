# Subscription Scanner

Telegram Mini App для поиска забытых платных подписок по банковской выписке.

## Кейс

Пользователь загружает выписку за 6 месяцев.
Приложение находит регулярные списания, объединяет похожие названия сервисов
и показывает, сколько денег можно сэкономить за год.
